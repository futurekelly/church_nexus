# ROLE SYSTEM

## SUPER ADMIN

Permissions:

* Full system control
* User management
* Role assignment
* Platform settings
* Security configuration
* Database maintenance
* Analytics access
* Financial overview
* Ministry management
* Content moderation

---

## PASTOR

Permissions:

* Manage sermons
* Publish devotionals
* View prayer requests
* Conduct livestream sessions
* Manage testimonies
* Create announcements
* Access church growth reports

Restrictions:

* Cannot modify system settings
* Cannot alter financial records

---

## CHURCH ADMIN

Permissions:

* Manage members
* Manage events
* Manage ministries
* Attendance tracking
* Visitor registration
* Community moderation
* Event coordination

Restrictions:

* No financial administration

---

## TREASURER

Permissions:

* Donations
* Tithes
* Offerings
* Financial reporting
* Expense tracking
* Budget management

Restrictions:

* No member role modification

---

## MEDIA TEAM

Permissions:

* Upload videos
* Upload images
* Manage livestreams
* Manage media gallery
* Publish recordings
* Moderate livestream chat

Restrictions:

* No financial access

---

## MEMBER

Permissions:

* View sermons
* Register for events
* Submit prayer requests
* Submit testimonies
* Join discussions
* View livestreams
* Manage personal profile

---

## VISITOR

Permissions:

* View public content
* Watch public livestreams
* Browse events
* Register account

Restrictions:

* Limited community access
* No internal member content
