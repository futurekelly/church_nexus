# UI GUIDELINES

## Design Direction

The application must follow a premium futuristic SaaS design language.

Primary style:

* Glassmorphism
* Dark theme
* Neon accent interactions
* Minimalistic layouts
* Smooth motion design

Avoid excessive neumorphism.

Use neumorphism only for:

* switches
* toggles
* radio controls
